## Featured Projects

### 🏨 Hotel Database — 3NF Normalization
Decomposed a flat hotel dataset into fully normalized relational tables (3NF) in PostgreSQL. Covers entity identification, functional dependencies, and clean schema design.

### 📚 Library Management System
A relational database system for managing books, members, loans, and fines. Built with PostgreSQL — includes DDL, DML, stored procedures, and indexes.

### 📊 Electronics Sales — Power BI Dashboard
Cleaned and transformed an electronics sales dataset using Power Query, then built an interactive Power BI report with sales trends, regional breakdowns, and KPI cards.

### 🌾 Kenya Crops — Agricultural Data Analysis
Cleaned and analyzed a Kenyan agricultural dataset in Power BI, covering crop yield trends and regional patterns.
