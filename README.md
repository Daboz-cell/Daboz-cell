# 👋 Hi, I'm Davy Baraka

I'm a data science student at KCA University, Nairobi, currently in the **LuxDev Data Science Cohort 7** program. I enjoy working with data — cleaning it, querying it, modeling it, and turning it into something that actually makes sense.

My work right now centres on SQL and relational databases, building dashboards in Power BI, and writing about what I learn along the way.

---

## 🧠 About Me:

- 🎓 Studying Data Science at KCA University, Nairobi
- 🛢️ Strong foundation in SQL — window functions, CTEs, subqueries, stored procedures, and normalization up to 3NF
- 📊 Building data dashboards and reports using Power BI and Excel
- 🐘 Working with PostgreSQL daily — DBeaver, pgAdmin, command line
- 🐍 Learning Python and R for data analysis
- ✍️ Technical writer — I document what I learn to reinforce and share it
- 📍 Based in Nairobi, Kenya
- 🚀 Continuously learning and pushing into new areas of data engineering
